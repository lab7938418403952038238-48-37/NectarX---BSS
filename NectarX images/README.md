# NectarX screen templates

Place tightly cropped PNG or BMP images of stable Bee Swarm Simulator / Roblox UI elements in this folder.

Tips:
- Capture them at the same display resolution and UI scale you use while running NectarX.
- Crop to a small, distinctive area that does not animate or change.
- The Screen Reader tab scans these templates inside the Roblox client window.
- Template matching is a first-pass test and may need tuning for your setup.

Do not add screenshots containing passwords, account details, or other private information.
